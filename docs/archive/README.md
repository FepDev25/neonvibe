# Archivo histórico

Documentos de las fases 0–11 de la construcción inicial del MVP. Se conservan
como referencia del trabajo realizado, **no como estado actual**: algunos
conteos, rutas y decisiones han cambiado desde entonces.

- `plans/` — plan de cada fase.
- `specs/` — especificación de cada fase.
- `reviews/` — revisión de cada fase (con datos de test de la época).

El estado vigente vive en `../ARCHITECTURE.md`, `../DEPLOY.md` y
`../pendientes.md`, y las convenciones en `../../AGENTS.md`.
